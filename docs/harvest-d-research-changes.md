# Harvest D Test Changes

The approved Harvest D update changes the planned campaign in four ways without expanding conceptual scope:

1. D0 mines existing Test 2 model/routing artifacts as diagnostic priors only; contaminated evidence cannot certify a capability boundary.
2. D3 records independent System-Involvement Telemetry and derives Architecture Intervention Ratio, Intervention Value, and Minimum Required Scaffolding.
3. The capability envelope is versioned and can change only through verified promotion/rollback.
4. D6B validates the capability ratchet: Qwen-discovered mechanisms must survive causal intervention vs sham, generalization, regression, and downward transfer to cheaper models/scaffolds before they count as capability expansion.

The planned Test 5 remains architecture optimization/compression rather than broad architecture discovery.
